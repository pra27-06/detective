PROJECT CREDITS & ARCHITECTURE

Project: CASE CLOSED — Detective Mystery Simulator

Architecture: C++17 Standard Library • Win32 / GDI+ • Pure ES6 Web Edition

Demonstrated OOP Principles:

  • Encapsulation: Private state in Character, Evidence, CaseFile, and SaveManager.
  • Abstraction: Pure virtual contracts in base Character class.
  • Inheritance: Detective, Suspect, and Witness inheriting from Character.
  • Runtime Polymorphism: Virtual dispatch across polymorphic collections.
  • Composition: CaseFile owns CrimeScenes, Evidence maps, and ClueBoard.
